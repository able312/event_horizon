## Calendar

### Navigation

W - move main calendar back a month
S - move main calendar foward a month
A - Move Mini Calendar back a month
D - Move Mini Calendar forward a month
Space - Sync main calendar to mini calendar
Cmd + T - Reset both calendars to today

Scroll up (on main calendar) - snap to previous month
Scroll down (on main calendar) - snap to next month

### Actions

Cmd + N - New Event
Cmd + P - Pretty Print the current month
